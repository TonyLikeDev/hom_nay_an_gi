# Middleware

Nơi đặt kiểm tra đăng nhập, quyền admin, dữ liệu đầu vào và xử lý lỗi dùng chung khi triển khai backend.

File dự kiến: `auth.middleware.js`, `validate.middleware.js`, `error.middleware.js`.

Hiện chưa có cơ chế xác thực. Không tạo middleware rỗng cho phép mọi yêu cầu rồi coi đó là bảo vệ API.

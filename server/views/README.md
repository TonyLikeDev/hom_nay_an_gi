# Views

Thư mục dành sẵn cho template render phía server nếu sau này dự án chọn EJS hoặc công cụ tương đương.

Hiện không dùng template engine: View thực tế là HTML/CSS/JavaScript trong `public/`. Thư mục này chưa được server phục vụ. Không sao chép các trang HTML vào đây vì sẽ tạo hai bản giao diện phải đồng bộ.
